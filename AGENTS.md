# DocsVibe — правила для агентов

Один файл для любого агента (Claude, Cursor, OpenClaw): `CLAUDE.md` — ссылка на него. Карта всех проектов и задач — `~/dev/oclaw/WORKSPACE.md`.

- Секреты (`.env`, токены, ключи) не коммитить.
- Анализ и отчёты не писать в эту папку — только в `~/dev/reports`.
- Николай дал общее правило вместе с задачей — после задачи предложить записать его сюда одной строкой (порядок — раздел «Дообучение» в карте).
