Прототип

Кликабельные экраны первой версии DocsVibe. Данные выдуманы. Это не продукт.

Открыть прототип отдельно — без оболочки книги. Ниже тот же образец в рамке.

Короткий путь: регистрация → письмо → вход → дашборд → шаблон в конструкторе или импорт → проект → ссылка → контрагент (приветствие, ответ или формулировка) → своя сторона ставит итог → версия для печати у обеих сторон. На широком экране согласования: статус сверху, оглавление слева, договор в центре, справа ссылка, реквизиты и обсуждение. На телефоне: одна строка сверху (проект, статус, меню), договор сразу в зоне чтения, снизу «N / M · Следующий», действия пункта в шторке. Печать — документ A4 под подпись, на экране «Распечатать или сохранить PDF». Настройки и реквизиты — из верхней полосы. Плашка «Режим прототипа» по умолчанию в одну строку; пометки «в книге ещё открыто» — по кнопке. Адрес экрана в хеше: «Назад» и обновление не выкидывают на вход, если открыть прототип отдельно, не в рамке книги.

Данные выдуманы. Хранение в коде не решаем. Открытые вопросы помечены «в книге ещё открыто» только в режиме прототипа. Кликабельный образец совпадает со списком экранов в устройстве продукта.
